Prompt de la agenda

Quiero que me crees una aplicación web en un solo archivo HTML para organizar mi día a día como profesor de secundaria. Llámala «[Mi agenda del profe]».

SOBRE MÍ
- Doy [materia] en [cursos y grupos, por ejemplo 2.º ESO A, 2.º ESO B y 1.º Bachillerato C].
- Mis clases duran [60] minutos. El curso termina el [23 de junio de 2027].

REGLAS (no se pueden quitar)
- Todo en español. Diseño limpio, que se use bien en el móvil y en el ordenador.
- Un único archivo HTML con su CSS y su JavaScript, sin bibliotecas ni servidores externos.
- La aplicación trabaja con grupos, nunca con alumnos: no tiene campos para nombres ni datos del alumnado.
- Nunca uses innerHTML con textos que escribo yo: usa textContent.
- Rellénala con datos de ejemplo inventados para que pueda probarla, y un botón para borrarlos y empezar.

DÓNDE SE GUARDAN LOS DATOS (muy importante)
La agenda será una aplicación web de Google Apps Script, creada desde una hoja de cálculo de mi Drive (Extensiones › Apps Script) y publicada para que solo yo pueda abrirla, desde cualquier dispositivo con mi cuenta. Dame dos archivos: Código.gs e Index.html.
- Código.gs: doGet() sirve Index.html, adaptado al móvil. cargarDatos() devuelve todos mis datos como texto JSON, o null si aún no hay nada. guardarDatos(texto) los guarda en una hoja llamada «Datos» de esta misma hoja de cálculo y devuelve la hora del guardado. Una celda admite 50.000 caracteres: si el texto es más largo, repártelo en varias filas, y guárdalo como texto para que la hoja nunca lo tome por una fórmula. Usa LockService para que dos guardados no se pisen.
- Index.html: todos los datos de la app van en un único objeto, que se guarda con JSON.stringify llamando a guardarDatos con google.script.run.
- Si google.script no existe (aquí, en la vista previa de Gemini), usa localStorage para que pueda probarla.
- Al abrir, muestra «Cargando…» hasta que lleguen los datos.
- Guarda solo cuando haya cambios: 3 segundos después del último cambio y, si sigue habiendo cambios sin guardar, cada 30 segundos. Nunca dos guardados a la vez.
- Arriba, siempre visible: «Guardado en Drive · 10:42», «Guardando…» o, en rojo, «Sin guardar · reintentando» si falla.
- Al volver a la pestaña (visibilitychange), si no hay cambios pendientes, vuelve a cargar para ver lo que haya cambiado desde otro dispositivo.
- Si intento cerrar con cambios sin guardar, avisa (beforeunload).
- Botones «Exportar copia» (descarga un JSON) e «Importar copia».
- Al final, explícame paso a paso dónde pego cada archivo y cómo la publico como aplicación web: ejecutar como yo, acceso solo yo.

APARTADOS QUE QUIERO (borra los que no quieras)
1. Horario semanal: tabla de lunes a viernes por franjas, con grupo y aula. Se edita pulsando en cada hueco.
2. Vista «Hoy»: al abrir, mis clases de hoy en orden, destacando la que toca ahora según la hora.
3. Programación de aula: por cada grupo, sus unidades o situaciones de aprendizaje, con las sesiones previstas para cada una.
4. Diario de sesión: en cada clase apunto lo que tenía planificado y lo que hice de verdad, y la marco como hecha, a medias o no hecha.
5. Arrastrar lo no hecho: lo que quede a medias o sin hacer pasa con un botón a la siguiente sesión de ese grupo.
6. Sesiones que me quedan: con los festivos que yo escriba y las fechas de fin de trimestre, calcula cuántas sesiones me quedan con cada grupo y si voy adelantado o retrasado respecto a la programación.
7. Exámenes y entregas: fechas por grupo, con aviso si faltan menos de 3 días o si un grupo tiene dos en la misma semana.
8. Mis tareas: lista de pendientes (corregir, preparar, papeleo) con fecha y prioridad.
9. Reuniones y guardias: claustros, equipos docentes, tutorías y guardias en el calendario.
10. Material para mañana: lista que se genera sola con lo que he anotado que necesito para las clases del día siguiente.
11. Notas del grupo: un comentario breve por clase sobre cómo fue el grupo.
12. Reflexión semanal: los viernes, tres preguntas (qué funcionó, qué cambiaría, qué necesito).
13. Imprimir la semana en una sola hoja.

COLORES Y ESTILO

/**
 * Mi agenda del profe · Almacén en tu Drive
 *
 * Copia este archivo tal cual: no hace falta tocarlo.
 * La agenda guarda sus datos en la hoja «Datos» de esta misma hoja de cálculo,
 * en tu Drive de educaand. Solo tú puedes abrirla.
 * Para recuperar una versión anterior: Archivo › Historial de versiones.
 *
 * @OnlyCurrentDoc
 */
var HOJA_DATOS = 'Datos';
var TAMANO_TROZO = 45000; // una celda admite 50.000 caracteres

function doGet() {
  return HtmlService.createHtmlOutputFromFile('Index')
    .setTitle('Mi agenda del profe')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1')
    .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
}

function hojaDatos_() {
  var libro = SpreadsheetApp.getActiveSpreadsheet();
  var hoja = libro.getSheetByName(HOJA_DATOS);
  if (!hoja) {
    hoja = libro.insertSheet(HOJA_DATOS);
    hoja.getRange('A1').setValue('No edites esta hoja: aquí guarda la agenda sus datos.');
  }
  return hoja;
}

/** Devuelve los datos guardados (texto JSON) o null si aún no hay nada. */
function cargarDatos() {
  var hoja = hojaDatos_();
  var ultima = hoja.getLastRow();
  if (ultima < 3) return null;
  var valores = hoja.getRange(3, 1, ultima - 2, 1).getValues();
  var texto = valores.map(function (fila) {
    var v = String(fila[0]);
    return v.charAt(0) === '~' ? v.slice(1) : v;
  }).join('');
  return texto || null;
}

/** Guarda los datos (texto JSON) y devuelve la hora del guardado. */
function guardarDatos(json) {
  if (typeof json !== 'string' || json.length === 0 || json.length > 2000000) {
    throw new Error('Los datos no son válidos.');
  }
  JSON.parse(json); // si no es JSON válido, no se guarda nada
  var bloqueo = LockService.getScriptLock();
  bloqueo.waitLock(15000);
  try {
    var hoja = hojaDatos_();
    var trozos = [];
    for (var i = 0; i < json.length; i += TAMANO_TROZO) {
      // «~» delante: ningún trozo empieza por = + - @ y la hoja no lo toma por fórmula
      trozos.push(['~' + json.slice(i, i + TAMANO_TROZO)]);
    }
    hoja.getRange(3, 1, trozos.length, 1).setNumberFormat('@').setValues(trozos);
    var ultima = hoja.getLastRow();
    var sobran = ultima - 2 - trozos.length;
    if (sobran > 0) hoja.getRange(3 + trozos.length, 1, sobran, 1).clearContent();
    var ahora = new Date().toISOString();
    hoja.getRange('A2').setValue('Último guardado: ' + ahora);
    SpreadsheetApp.flush();
    return ahora;
  } finally {
    bloqueo.releaseLock();
  }
}
